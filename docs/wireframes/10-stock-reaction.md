# Wireframe: Stock reaction

## Purpose

Annotated price chart with ChatGPT, earnings, DeepSeek using reactionPct for intraday news.

## Layout

- Desktop: editorial measure for prose; charts break to wide/broad.
- Mobile: single column; sticky exhibits unpin.

## Visualization choice

See the matching exhibit component. Chart exists only if it answers a business question.

## Interaction

Scroll reveals, story-clock beats where applicable, reduced-motion static branch.
