# Microsoft announces third-phase multibillion-dollar OpenAI investment

- **Date:** 2023-01-23
- **Category:** ecosystem
- **Precision:** exact

## What happened

Microsoft announced a multiyear, multibillion-dollar investment as the third phase of its OpenAI partnership, following investments in 2019 and 2021, with Azure remaining OpenAI's exclusive cloud provider for research, API and product workloads. Microsoft did not disclose the amount; Bloomberg reported the figure as $10 billion.

## Why it mattered

The commitment underwrote a multi-year Azure AI supercomputing build that was the single largest source of NVIDIA data-centre demand in fiscal 2024, and set the template of capital-for-compute deals later replicated by NVIDIA itself with OpenAI and Anthropic.

## Quantified impact

Amount not disclosed by Microsoft; reported by Bloomberg as $10 billion. Prior phases: $1 billion (2019) and an undisclosed 2021 round.
