# CUDA SDK and C compiler released in public beta

- **Date:** 2007-02-16
- **Category:** product
- **Precision:** exact

## What happened

NVIDIA released a public beta of the CUDA Software Developer Kit and C compiler for Windows XP and Linux, making GPU computing available to any developer rather than to research partners only. CUDA 1.0 followed as a general release in June 2007.

## Why it mattered

Free, broad distribution of the toolchain seeded an academic and scientific developer base years before there was a commercial AI market, which is why deep-learning researchers in 2010-2012 defaulted to NVIDIA hardware.
